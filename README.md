# Maisonette Hotel - Website and Operations Portal

ASP.NET MVC application for **Maisonette Hotel**, combining a marketing/booking website with administrative management tools.

## Overview
Supports guest browsing and booking journeys plus staff tools for property configuration, content, and reservation handling.

## Key Features
- Public hotel pages and booking experience
- Room/property administration
- Reservation and payment-related workflows
- Responsive UI assets
- SQL Server-backed MVC architecture

## Tech Stack
- **Backend:** ASP.NET MVC (C#), .NET Framework 4.7.2
- **Frontend:** Razor, JavaScript, jQuery, Bootstrap
- **Database:** Microsoft SQL Server + Entity Framework
- **Solution:** `HotelWebsite.sln`

## Getting Started
1. Open `HotelWebsite.sln`
2. Configure database connection strings
3. Restore NuGet packages
4. Build and run
